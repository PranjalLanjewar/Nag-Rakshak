# NagRiver Sentinel — Data Models & Schema Contract

All modules (Frontend, Backend, Vision AI, Satellite Engine) **MUST** communicate using these exact object structures and field names.

The primary key linking all objects across components is `segment_id`.

---

## 1. River Segment (`Segment`)

Represents a geographical segment of the Nag River.

```typescript
interface RiverSegment {
  segment_id: string;          // Format: "nag-seg-001"
  name: string;                // e.g. "Ambazari Spillway to Krazy Castle"
  length_km: number;           // Segment length in kilometers
  coordinates: [number, number][]; // GeoJSON LineString coordinates [[lng, lat], ...]
  centroid: [number, number];  // Center point [lat, lng] for map zooming
  investigation_priority_score: number; // 0 – 100
  priority_level: 'Low' | 'Moderate' | 'High' | 'Critical';
  last_updated: string;        // ISO 8601 Timestamp
}
```

---

## 2. Satellite Metrics (`SatelliteMetrics`)

Calculated by Person 4 (Satellite module using Google Earth Engine Sentinel-2 dataset `COPERNICUS/S2_SR_HARMONIZED`).

```typescript
interface SatelliteMetrics {
  segment_id: string;
  ndwi: number;               // Normalized Difference Water Index (-1 to +1)
  mndwi: number;              // Modified NDWI (-1 to +1)
  ndti: number;               // Normalized Difference Turbidity Index (-1 to +1)
  ndvi: number;               // Normalized Difference Vegetation Index (-1 to +1)
  temporal_change_percent: number; // Change compared to previous satellite pass
  satellite_score: number;    // 0 – 100 (Calculated index score)
  cloud_cover_percent: number;// Cloud coverage during satellite pass
  acquisition_date: string;   // Date of satellite image capture
}
```

---

## 3. Ground Evidence (`GroundEvidence`)

Created when users/field agents upload a ground photo (Person 3 Vision AI).

```typescript
interface GroundEvidence {
  id: string;
  segment_id: string;
  photo_url: string;
  uploaded_at: string;
  location: {
    lat: number;
    lng: number;
  };
  ai_analysis: {
    waste_detected: boolean;
    foam_detected: boolean;
    discoloration_detected: boolean;
    bank_degradation_detected: boolean;
    confidence_score: number; // 0 – 1.0
  };
  ground_score: number;        // 0 – 100 (Score generated by Vision AI)
  notes?: string;
}
```

---

## 4. Fused Priority Record (`FusedPriorityRecord`)

Computed by Person 2 (Backend Evidence Fusion Engine).

```typescript
interface FusedPriorityRecord {
  segment_id: string;
  satellite_score: number;
  ground_score: number | null; // null if no ground photo present
  has_ground_data: boolean;
  investigation_priority_score: number; // Fused score (0 - 100)
  priority_level: 'Low' | 'Moderate' | 'High' | 'Critical';
  evidence_agreement: 'High Agreement' | 'Moderate Agreement' | 'Discrepancy Detected' | 'Satellite Only';
  recommended_action: string;
  calculated_at: string;
}
```
