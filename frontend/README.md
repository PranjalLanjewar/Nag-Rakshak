# 🎨 Frontend Module (Person 1 Ownership)

React + Vite + Leaflet + Tailwind CSS dashboard UI for NagRiver Sentinel.

## 🚀 Running Dev UI

```bash
npm install
npm run dev
# App starts at http://localhost:5173
```

## 🗺 Features

- **Interactive Leaflet Hotspot Map**: Renders Nag River segments from GeoJSON colored by Investigation Priority Score.
- **Evidence Panel**: Displays satellite metrics (NDWI, MNDWI, NDTI, NDVI), temporal change, ground verification photos, and Vision AI detections.
- **Ground Photo Upload**: Upload field photos to trigger Vision AI & re-fuse evidence scores.
